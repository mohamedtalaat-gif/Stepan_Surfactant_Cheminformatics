# Corrections

This is a single-author record of the seminar, so I keep the content under one hand. A correction is welcome as an issue: give the deck,
the page and the value as you read it on the slide, and the row of `data/` that differs. A transcribed value that does not match its slide
is a defect; so is a notebook sentence that says more than the slide does.

Before a change is merged:

* source-derived values keep their deck and page;
* `q.s.` stays a q.s. instruction and is never replaced by a guessed percentage;
* a calculation is labelled *derived* or *modelled* and is not presented as a result;
* `uv run pytest` and `uv run marimo check notebooks/*.py` pass.
